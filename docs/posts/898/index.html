重温《天才是不存在的》

2023-03-12

重温了一下我写于 2017 年的这篇文章《天才是不存在的》，感叹这几年来我思想的进化。我对待“天才”这个词的态度，经历了好几个阶段的变化。

1. 起初，我仰慕“天才”，就像很多人一样。我并不真的理解天才们的“成就”，却把他们的话很是当回事，就因为大家都说他们是“天才”。

2. 我想成为天才，却发现很难。因为媒体把天才们的能力描述得如此神奇，试图做到一样的事情，只能深感挫折。

3. 我发现我并不需要做到天才们那些“神奇”的事情，但我能达到和他们相似甚至更深刻的理解。我觉得自己就是天才，这才是天才的真正意义。

4. 经过调查，我发现曾经仰慕的那些“天才”，其实都不是那么聪明，而是被人吹捧出来的。我发现自己也不是什么天才，其实任何正常人都可以做到这些事，天才这种东西本来就是不存在的。
