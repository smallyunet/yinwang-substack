回顾《成都的雾霾》

2023-03-10

回顾了一下我写于 2018 年的《成都的雾霾》一文http://www.yinwang.org/blog-cn/2018/02/16/chengdu-pollution，觉得当时还是有很多事情没有看明白，但这篇文章很有记录价值，所以把它重新放到了博客上。你可能需要翻墙才能看我的博客，因为我在疫情期间写了一些 Matrix 不想让国内人看到的内容，比如揭露疫情是骗局之类的http://www.yinwang.org/blog-cn/2022/06/25/covid-19，所以后来博客被墙了。

2018 年的这篇文章中的理解，雾霾不是由汽车尾气产生的，这是对的。但当时我认为是工厂在偷排污染物，那是错误的。而且当时我还是相信「pm2.5 有害」那套理论，而没有发现关键问题其实不是颗粒物的尺寸，而是颗粒物里面的化学成分是否有毒。

现在我已经看得很清楚，国内的雾霾是在故意放毒。实际上世界上所有地区的严重“雾霾”都是在故意放毒，而不是“空气污染”。工厂是不能产生这么严重的雾霾的，而且工厂无法产生雾霾的“周期性”。由于雾霾是使用特殊的设备故意放出来的，所以才能这样想开就开，想停就停，还可以随意更换里面的化学成分。就是这么简单。
