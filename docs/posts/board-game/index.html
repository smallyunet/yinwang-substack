Board Game 真的很无聊

2023-09-09PAID原文链接

最近参加了不少 social 活动，其中有些里面出现了 board game。经常在西方人 party 里都会出现这种游戏，类似 monopoly（大富翁）。每次看到这种游戏我都觉得很无聊，没有动力去玩。有时候为了 social 就勉强玩一下，但每一次都让我觉得无聊透顶。有时候还有那种专门的“board game 聚会”，那我就是完全不会参加的。

有朋友问我喜不喜欢 board game 的时候，为了不伤感情，我总是找个借口说：“我觉得这些游戏太复杂了，太烧脑。” 但是他们会对我说：“你这么聪明的人，程序都能写那么好，怎么会觉得 board game 烧脑呢？” 然后继续怂恿我参加。

其实我没有直接说出来的原因是这样的，并不是我没能力去理解这些游戏的规则，而是我不愿意去理解别人设计的游戏规则。所以我说这些…
