化学尾迹可能喷洒臭氧（O3）

2023-03-13原文链接

化学尾迹不一定都撒的都是用于让人生病的有毒物质，也可能有其它用途，因为里面的成分是随时可以换的，可以满足不同时期的不同需求。去年 7-8 月在上海看见化学尾迹的时候，我同时发现空气质量数据里的 O3（臭氧）含量很高。同时间，成都等地也出现了化学尾迹，而且出现 O3 很高的情况。

要知道臭氧是温室气体，它的保温能力是二氧化碳的 1000 倍。我猜他们那段时间在天上撒的是臭氧，这样人们就会觉得热得像烤箱一样，就觉得全球变暖是真的。然后就可以顺理成章怪到二氧化碳头上，然后给燃料和烧油的车加价，收取各种额外的“碳排放税”，等等。
