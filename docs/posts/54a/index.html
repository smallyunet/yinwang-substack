大型天文台也都是假的

2023-04-29

上次谈到从我买的天文望远镜看到一些小亮点，我就以为它们是“人造卫星”，而它们其实可能是地球的“天然卫星”，就像月球一样，一直在绕着地球高速飞行，并不是人类发射上去的。

有人可能以为从大型天文台的望远镜，就能看到这些东西的细节。但忽然想起来，我从来也没看见过天文台用望远镜拍下来的“人造卫星”或“国际空间站”的照片啊。而且这提醒了我一件事——天文台的望远镜不仅没拍到过人造卫星，我从来也没看到过从天文台的大型望远镜实拍的任何照片……

于是我就到 YouTube 搜索天文台的视频，确认了一下，果然如此。介绍天文台的那些视频，只有天文台本身的外观，望远镜的外观，却没有一张从望远镜实拍的照片。

本来看到这样的场景，巨大的望远镜对着夜空，下一步就应该看到望远镜里的图像，然而却没有。视频里那些超清晰的“宇宙照片”，显然都是电脑合成的。

还有很多其它介绍天文台的视频，一看一个准，里面只有电脑合成动画，一张实拍的宇宙照片都没有。

想想，如果天文台的望远镜能看到那么清晰的图像，为什么介绍天文台的影片还要用电脑动画，而不是实拍的呢？你知道做电脑动画有多费事，成本多高吗？为什么有个望远镜摆在那里，随便拍一下就超级好的效果，却要费这么大工夫去做电脑动画呢？

如果这些大型望远镜真能看到非常清晰的图像，肯定有天文台会给望远镜的目镜处装上“天文摄像机”，在网络上直播天文观测的过程。然而却没有这样的直播，甚至连照片都找不到一张。

这个世界太神奇了。搜遍整个网络，找不到一张从太空实拍的星空照片，找不到一张从天文台的大型望远镜实拍的照片。我感觉这是在给人类做某种“弱智测验”，看看什么时候才会有人发现这么明显的剧情漏洞。那些什么“太空望远镜”当然都是假的，然而没想到地面上的天文台也都是假的。看来没有一台望远镜真能把星星看得很清楚。

所以我猜，望远镜无论口径有多大，它的能力都是非常有限的。这可能是因为制造高精度的大型反射镜（或透镜）是非常困难的。反射镜不能保持很精确的形状，它们会受到自身重量，气温，气流，地面震动等干扰。所以虽然反射镜有那么大，但这些镜面反射的光，并不能准确地汇聚到它们该到的位置，形成清晰的图像。反而可能由于口径太大，干扰的光太多，而没法清晰成像。

另外，从遥远的宇宙来的光线，经过大气层的时候，会受到空气的扭曲。空气的密度存在差异和波动，在不停地随机变化中，所以看到的图像会在不停波动中，无法清晰成像。我的望远镜看很远的地方就是这样，像是在看火炉对面的东西，图像不停晃动。这种光线扭曲无法被光学设备更正，因为光线到达望远镜之前就已经失真，无法还原。所以我猜，这些大型望远镜并不比普通的业余望远镜强很多，仍然只能看到一些晃动的小亮点。

所以看起来，不仅所有的“太空计划”都是假的，而且世界上所有的大型天文望远镜也都是假的，它们并不能让人们看到清晰的宇宙图像。不然为什么整个网络找不到一张从这些望远镜实拍的照片？天文台和宇航部门应该都是 Matrix 的同一个部门控制的，所以合作制造同样的骗局，这个可以理解。我们被天文学家告知的关于宇宙的一切，都值得怀疑。

有人可能以为可以亲自去天文台看看，不就能确认了吗？去试试吧，这些大型天文台最多只会让你参观一下外观，是不会让你实际使用那些望远镜的，不然就露馅了。当然，他们的借口是这望远镜极其昂贵和精密，怕你把它弄坏了，所以只能让你站在远处参观一下。而且这些最大的天文台，都建在很偏远的地方，悬崖峭壁上面或者沙漠里，很少有人会去那种地方，就是故意让人不容易去。

小型的天文台可以让你用里面的望远镜，但其实看不清什么东西，最多看看土星光环，而且很小很模糊。你看不清更远的东西，他们就跟你说因为这个天文台的望远镜不是最大的那种，还比较小。然而，自己买的天文望远镜其实也能看到土星光环。你只好期待有天能用上世界上最大的那些望远镜，但别人是不会让你用的，因为一用就露馅了。
