别让别人教你怎么跑

2026-08-04原文链接

看了 YouTube 推荐的三个教“专业跑法”的视频，发现全是误导。

看来体育运动都是这样的，网络上绝大部分信息都是误导。

之前我提到过在日本参加一个“跑团”的故事。新来的一个领跑者居然问我：“你是从什么时候开始跑步的？（When did you start running?）” 我说：“Since I was born.” 他还很惊讶的样子。

其实我的意思是，我生下来学会了走路，后来就会跑了。按照「running」这个词的定义，确实就是如此。谁还不会跑呢？

但总是有人跟你说，这样的跑姿不对，你要这样那样着地才是科学的，专业选手不是你那样跑的。你这样跑平时可以，但跑不了马拉松……

如果你听信了他的，过一段时间也许就会发现——你受伤了。

别听这些人鬼扯“怎么跑”。每个人，每只动物都会跑。有本事你去教教猫，狗和猎豹怎么跑？它们专业地学过吗？世界上有人跑得过哪怕一只普通胖猫吗？

人一般1岁半到2岁就会跑了。没人需要别人来教自己怎么跑。
