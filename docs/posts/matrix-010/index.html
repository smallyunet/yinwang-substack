Matrix 在扭曲人类的认知

2023-04-10

关于尾迹的事情，我问过几个英国人，他们都认为“飞机本来就是那个样子的”。之前在伦敦住的酒店，里面很浓的空气清新剂味道，我也问过几个人，他们都说没闻到，或者“就是正常的空气清新剂”。

我就想起以前住在旧金山的时候，我曾经每天都去附近的一个中餐馆吃饭。他家的菜一般般，但还可以吃，也比较近，我就那样凑合着。结果有一天，我点的一个炒肉，一吃就发现肉是臭的，根本没法吃。我就跟老板说，这个肉味道不对，是臭的。她过来闻了一下，跟我说：“肉就是那个味道的呀！”

“肉就是那个味道的呀”。她的意思好像是我从来没吃过肉，所以对肉的味道大惊小怪的。我活了几十年，没吃过肉，不知道肉应该是什么味道？听了这话，我之后就再也没去过那家饭店。我对待这个事情一向很坚决，一旦出现这种情况，还拒不承认，我是绝不会再给他们一次机会的。

又想起之前在大学，发现发论文都是言之无物，甚至弄虚作假，人们也说“那是正常的”，“随着游戏规则玩吧”。没想现在到了英国，遇到这些放毒的事情，人们都像这家饭店一样，觉得那是“正常”的。

人类世界太多不正常的事情，被如此的扭曲，说成是“正常”的。指出问题的人都被认为是“大惊小怪”。年复一年，于是人类走到了今天，一步步地走向悬崖的边沿。只是这一次，人们将要失去的不只是天真和良知，而是健康和生命……

这一切都是 Matrix 计划中的。虽然登月，核武器什么的都是假的，但 Matrix 扭曲人的认知和灵魂的手法，真是高深莫测。
