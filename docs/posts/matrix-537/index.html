爱因斯坦是 Matrix 的演员

2023-02-17原文链接

根据之前对相对论和 E=mc^2 的分析，我觉得爱因斯坦并不是一个科学家，而是秘密跨国犯罪团伙（以后简称Matrix）给我们安排的一个演员。爱因斯坦被树造为一个开天辟地，超越牛顿的天才。他扮演着这个角色，“提出”了Matrix 给他准备好的一些“理论”。这些并不是真正的科学理论，它们被提出的目的只是用于支持原子弹存在的假象，然后就可以用核武器造成的恐惧来控制人民。

爱因斯坦的“天才”形象和这些理论的另一个用途，是把科学引入歧途，走进死胡同，成为一种不可置疑的，跨国界的宗教（邪教），这样就没人再能发现世界真正在发生什么。此后，Matrix 继续造出一大堆假科学，并且导致整个学术界的腐败变质。这也就是为什么我会连续抛弃三个博士学位，因为我发现读博士都得发表一些毫无意义的论文，里面极少有真正的发现。现在看来，这一切都是有人在背后操纵，而不是自发的现象。

相对论的基础 Michelson-Morley 实验之所以能被科学界接受，也是同样的原因，都是 Matrix 的安排。这就是为什么即使 Dayton Miller 等人做了更仔细的实验，说明 Michelson-Morley 实验的结论（相对光速不变）是错误的，科学界却忽视他们的结果，不是严谨地重复验证，而是盲目地接受 Michelson-Morley 实验的结论。科学界是受 Matrix 操纵的，所有的新闻和科学期刊都是 Matrix 操纵的，人们却以为它们是自由公正的。这些都是在为爱因斯坦的“相对论”做铺垫。这个错误很不容易被发现，因为它绝大部分是对的，而不是完全荒谬。Matrix 能想出这样的计划，安排之周密，令人叹为观止。
